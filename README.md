# ViraCalendar 💜

Calendário privado de vídeos para TikTok Shop: organize pelo computador, acesse pelo celular e faça download do conteúdo do dia.

**Status:** interface web e integração com Supabase em implantação. O GitHub Pages hospeda a interface, não os vídeos.

Veja [CONFIGURACAO.md](CONFIGURACAO.md) para ativar o armazenamento na nuvem, banco de dados, login e GitHub Pages.

## O que o aplicativo faz
- Calendário mensal responsivo com contagem de vídeos por dia
- Upload em lote com agendamento individual
- Organizar vídeos por produto e data
- Visualizar vídeo, baixar o arquivo original e marcar como postado
- Mover para outra data ou excluir vídeo
- Login por email e senha
- Armazenamento privado com políticas de segurança

Não faz postagem automática em plataformas, nem transforma clipes.
